# Jejak Benang 2035 — Mockup Interaktif

Mockup aplikasi *Immersive Carbon-Aware Shopping* untuk fashion berkelanjutan, disusun sebagai Bonus Challenge UTS mata kuliah Sustainability Global Marketing (Magister Manajemen, FPEB Universitas Pendidikan Indonesia).

**Buka mockup:** `https://<username>.github.io/<nama-repo>/`

## Alur yang bisa dicoba

1. **Beranda** → ketuk *Pindai sekarang*.
2. **Kamera AR** → tekan tombol rana; label AR muncul di kemeja.
3. **Detail produk** → lihat bukti blockchain, ketuk tahap emisi, putar babaknya di VR.
4. **Carbon Journey (VR)** → lima babak siklus hidup kemeja.
5. **Bandingkan** → pilih kemeja, baca alasan saran AI, lalu beli.
6. **Pesanan & poin** → +20 Carbon Points untuk pilihan rendah karbon.
7. **Dampakku** → poin, CO₂e yang dihindari, tukar hadiah.
8. **Dasbor Merek** → data sesi dan simulasi skor karbon.

Layar tertentu bisa dibuka langsung dengan parameter `?start=`:
`scan`, `scanned`, `product`, `proof`, `journey`, `compare`, `success`, `impact`, `brand`.

> Semua angka, merek, dan harga pada mockup ini adalah data simulasi untuk ilustrasi.
